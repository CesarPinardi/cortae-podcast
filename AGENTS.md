# Fluxo de alterações

Para cada tarefa que alterar arquivos deste repositório:

1. Trabalhe em uma branch com o prefixo `codex/`; crie-a antes da alteração se ela ainda não existir.
2. Ao concluir, execute as verificações relevantes, faça um commit que inclua somente as mudanças da tarefa, envie a branch e abra um pull request.
3. Se não for possível criar ou enviar o pull request, informe o bloqueio e a causa no encerramento.
